# ADR Template
The following template was based on templates and other examples available [here](https://architecture-decision-record.github.io/) by [Joel Parker Henderson](https://github.com/joelparkerhenderson).

Copy the template below:

# Title

## Context
[Describe the context of the issue, challenge or feature]

## Options considered
[A list of possible solutions or implementations]

## Decision
[The solution chosen and a description of **why**]

## Consequences
[A list of consequences from adopting said solution, both positives and negatives]
